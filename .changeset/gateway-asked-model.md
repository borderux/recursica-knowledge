CircleChat host kit: the gateway's spend log notes a request that names no route. Such a request, for example one naming a model, still goes to the agent's first route, as before, and its line now carries `asked`, the name it gave (cut to 80 characters). An agent asks for a route by its role and never names a model, so `asked` shows any agent or tool that still does. A later change can refuse these requests once the log stays clear.
